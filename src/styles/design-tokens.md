# Design Tokens

En attente d'un nouveau design à reproduire. Une fois le fichier Figma /
les screenshots de référence fournis (voir `design-refs/`), documenter ici :

- Couleurs (neutres, marque, accents)
- Typographie (familles, tailles, graisses, line-heights)
- Espacements & rayons
- Composants récurrents identifiés

Voir `CLAUDE.md` pour le workflow complet.
